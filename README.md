# EQ-Algebras Verification in SageMath

This repository contains a computational study and verification of finite EQ-algebras and their prefilters using Python/SageMath.

## 📌 About the Project
The script eq-algebra.py defines a finite EQ-algebra structure and verifies its fundamental axioms (E1 to E7) computationally. It also includes checks for prefilter and integral prefilter conditions.

## 🚀 How to Run
You can run this script using Python or SageMath. 
Make sure you have Python installed, then run:

```bash
python eq-algebra.py
```

## Verification Results
The script outputs the boolean result of each axiom (True/False) and determines whether the defined structure is a valid EQ-algebra and if the given set is a prefilter.
